I build websites and web apps for property agents, agencies and small businesses: sites that list properties, capture enquiries and are easy to keep up to date. Every project is priced by a written quote before work starts.

- **Real estate websites**: Listing and search pages, enquiry capture and landing sites for property agents and agencies, easy to keep up to date. Example: https://devshipit.com/work/rentwise/
- **Full-stack web apps**: Next.js, Node and PostgreSQL apps with real-time updates and map search, like RentWise. Example: https://devshipit.com/work/rentwise/

## How a project works

1. **Tell me what you need**: Email a few lines: what it is, when you need it and a rough budget. I reply within 2 working days.
2. **Get a written quote**: Scope, price and delivery dates, agreed before any work starts. You pay only the amounts in the quote.
3. **I build it**: I design and build what the quote describes, from the database to the interface.
4. **Delivered online**: A live website, a code repository or files, on the dates in your quote. Once paid for, it is yours.
